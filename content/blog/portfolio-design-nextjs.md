# Designing My Personal Portfolio with Next.js

When I set out to build this portfolio, I wanted it to be more than just a list of links. It needed to reflect my philosophy as both a designer and a developer: finding the perfect balance between beautiful aesthetics and clean code.

## Visual Language
I opted for a soft, light-themed visual language. Using delicate lavender and purple gradients, frosted glassmorphism elements, and smooth animations, I aimed to create a premium, calm reading experience.

## Architecture
Under the hood, this site is powered by Next.js (App Router). I chose a file-based Markdown system for my blog and projects to keep content management simple and developer-friendly without needing an external CMS.
