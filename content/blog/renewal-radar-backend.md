# Building Renewal Radar as My First Backend-Focused Project

Transitioning from a heavily front-end focused mindset to building a robust backend was a transformative experience. Renewal Radar was born out of a real need: keeping track of expiring domains and SSL certificates before they caused downtime.

## The Tech Stack
- **Node.js & Express:** For the core API and scheduling logic.
- **PostgreSQL:** For structured, relational data storage.
- **Cron Jobs:** To run daily checks on expiration dates and trigger alerts.

## Overcoming Backend Challenges
One of the biggest hurdles was setting up reliable background tasks that wouldn't fail silently. Learning about error handling, database transactions, and proper API design fundamentally changed how I think about full-stack development.
