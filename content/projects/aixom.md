# Aixom: Building the Best Together

Between October and December 2024, I served as a **Front-End Developer** for the Aixum IT Group, designing and building the front-end for their main company platform. 

## Key Responsibilities
- **Vue.js Architecture:** Built the core application logic and reusable components using Vue.js.
- **Bilingual Support:** Engineered the site to seamlessly support two languages, ensuring proper layout and typography for both LTR and RTL orientations.
- **API Integration:** Integrated RESTful APIs for real-time data interactions, utilizing API documentation tools for comprehensive testing and validation.
- **Smooth UX:** Focused heavily on creating a dynamic, smooth, and engaging user experience that reflects the company's commitment to modern technology.

The resulting platform successfully represents Aixom's digital identity and serves as a robust foundation for their online presence.
