# Golderin (Goldshop)

Golderin is a comprehensive platform designed for tracking and analyzing the financial markets in Iran. Built as my first major foray into working with external APIs, it aggregates live data for gold, coins, and foreign currencies to provide users with up-to-date market insights.

## Core Features

- **Live Market Data:** Real-time fetching and displaying of prices for various assets including Dollar, Euro, and Gold Coins.
- **Interactive Charts:** Visual representation of price trends over time using interactive bar charts, making it easy to analyze market movements.
- **Clean UI:** A minimalist, light-themed interface with gold and green accents that prioritizes data readability and user experience.
- **Responsive Design:** Ensures that users can check market prices seamlessly across desktop and mobile devices.

## Technology Stack

- **Frontend:** React
- **Data Visualization:** Chart.js
- **API Integration:** RESTful APIs for real-time data
- **Styling:** Custom CSS with a focus on modern, clean aesthetics
