# MoonBlog

MoonBlog is a minimal, elegant blogging template crafted specifically for writers, software engineers, and designers who want their words to stand out. It features an ultra-clean reading layout, dark-mode styling, and excellent typography.

## Core Features

- **Blazing Fast Performance:** Statically pre-rendered pages with perfect lighthouse scores.
- **MDX Support:** Write articles in Markdown with inline React components.
- **Reading Time Estimation:** Keep readers informed with automatic word-count metrics.
- **SEO & RSS Out-of-the-Box:** Includes XML sitemaps, semantic layout, and RSS feed support.

## Technology Stack

- **Framework:** Next.js (Static Site Generation)
- **Content:** MDX (Markdown + React Components)
- **Styles:** Tailwind CSS with custom typography plugins
- **Icons:** Lucide Icons
