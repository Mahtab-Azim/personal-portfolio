# Personal Portfolio

This very website serves as a live demonstration of my design aesthetics, technical skills, and attention to detail. I built it from the ground up as a modern, performant showcase of my professional journey.

## Design Philosophy
My goal was to create a digital space that feels premium, dynamic, and uniquely mine. 
- **Glassmorphism & Isometric UI:** Custom-built 3D shapes and frosted glass effects using pure CSS, avoiding heavy image assets.
- **Deep Colors & Micro-interactions:** A meticulously chosen color palette paired with subtle hover states and animations to keep the user engaged.

## Technical Implementation
- **Next.js (App Router):** Leveraged React Server Components for optimal performance and SEO.
- **Content as Data:** Engineered a custom markdown parsing system (`gray-matter` + `marked`) to effortlessly manage my projects and blog posts without needing an external CMS.
- **Vanilla CSS:** Opted for CSS Modules over utility frameworks to maintain total, uncompromised control over complex styling and animations.

The result is a fast, SEO-friendly, and visually striking portfolio that grows alongside my career.
