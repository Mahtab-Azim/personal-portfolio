# Quix: Interactive Algorithm Platform

Quix was developed as a university class presentation project focusing on Computer Science algorithms. Built alongside our development team **aixom**, the goal was to create an interactive, visual platform to demonstrate complex algorithms in a digestible format.

## My Role
While the platform is heavily powered by a modern Django backend, I took charge of the **front-end implementation**. Translating algorithmic data structures into interactive, understandable UI components was a unique challenge that bridged the gap between pure computer science and user experience design.

## The Outcome
The resulting platform successfully turned abstract class concepts into an engaging, interactive web experience.
