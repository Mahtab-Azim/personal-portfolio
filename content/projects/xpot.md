# Xpot: Course Selling & Viewing Platform

I served as the **Front-End Developer** for Xpot, an educational e-learning platform designed for selling and viewing premium digital courses.

## Project Scope
The core requirement was to build a robust, secure, and user-friendly interface that could seamlessly integrate with **SpotPlayer** for secure video playback. 

## My Contributions
- **Independent UI Design:** I independently designed the interface, focusing on a dark, premium aesthetic suitable for focused learning.
- **Modern Tech Stack:** Built the responsive UI using **Tailwind CSS** and **Daisy UI** for rapid, consistent styling.
- **Dynamic Interactions:** Leveraged **HTMX** to create dynamic, SPA-like interactions without the overhead of a heavy JavaScript framework.
- **Deployment:** Collaborated closely with the backend team, utilizing **Docker** for streamlined, containerized deployment.

The result is a fast, responsive, and secure educational platform tailored for modern learners.
