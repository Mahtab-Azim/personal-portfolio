# Zentro

Zentro is a minimalist, high-performance dashboard application designed for remote teams who value clarity and efficiency. It consolidates task management, project planning, and performance metrics into a single, intuitive interface.

## Core Features

- **Real-time Collaboration:** Instant updates for task changes and comment threads.
- **Performance Analytics:** Clean, visually appealing charts indicating project velocity.
- **Customizable Layouts:** Kanban board, list view, and calendar timeline options.
- **Premium Glassmorphism Design:** A beautiful dark-themed environment that reduces eye strain.

## Technology Stack

Built with a modern stack focusing on performance and developer experience:
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** CSS Modules with Vanilla CSS Custom Properties
- **Database:** Prisma & PostgreSQL
- **State Management:** Zustand
